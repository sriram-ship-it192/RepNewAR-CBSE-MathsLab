Rangometry Kit — AR Marker Sheet

Print at 100% scale. Keep the two markers flat and visible to the webcam.

Tag #1 — Pivot

Place this marker at the fixed angle pivot.

Tag #2 — Moving Rod

Attach this marker to the moving rod and rotate it.

Classroom setup: Tag #1 stays fixed. Tag #2 moves with the rod. Open the Rangometry lesson and point the webcam at both markers. The AR angle is calculated from their tracked positions.

Quick activity

  1. Start the Rangometry lesson.
  2. Show both markers to the camera.
  3. Set the rod near 60°.
  4. Rotate it to 90°, then 120°, then 180°.
  5. Ask students to name each angle type.
